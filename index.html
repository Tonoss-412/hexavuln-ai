# The HexaVuln Process

1. Researcher finds anomalous behavior.
2. Researcher drops evidence into HexaVuln workspace.
3. Claude reasons about potential root causes and affected components.
4. Researcher manually validates the hypothesis.
5. Claude drafts a comprehensive Markdown report.
6. Researcher signs off and submits.
